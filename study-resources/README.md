# Free Study Resources

Free (or free tier) resources I use or recommend for learning cybersecurity, certifications, and scripting.

> 💡 Free tiers and offers change over time, so always check the site for current details.

## Certification Prep

| Resource | What it covers |
|----------|----------------|
| [Professor Messer](https://www.professormesser.com/) | Free video courses for CompTIA Security+, Network+, and A+ |
| [Microsoft Learn](https://learn.microsoft.com/en-us/training/) | Free learning paths for Microsoft certs like SC-900, AZ-900, and SC-200 |
| [ISC2 Candidate Resources](https://www.isc2.org/) | Info and training for entry level certs like Certified in Cybersecurity (CC) |
| [Cisco Networking Academy](https://www.netacad.com/) | Free intro courses on cybersecurity and networking |
| [Fortinet Training Institute](https://training.fortinet.com/) | Free self paced security awareness and network security courses |

## Hands On Labs (Blue Team and SOC)

| Resource | What it covers |
|----------|----------------|
| [TryHackMe](https://tryhackme.com/) | Guided, beginner friendly labs with many free rooms |
| [LetsDefend](https://letsdefend.io/) | SOC analyst simulator with alerts to investigate |
| [Blue Team Labs Online](https://blueteamlabs.online/) | Free defensive investigations and challenges |
| [CyberDefenders](https://cyberdefenders.org/) | Blue team challenges in forensics, threat hunting, and network analysis |
| [Splunk Training](https://www.splunk.com/en_us/training.html) | Free Splunk eLearning courses for log searching and SIEM skills |

## Hands On Labs (Red Team and Web App)

| Resource | What it covers |
|----------|----------------|
| [PortSwigger Web Security Academy](https://portswigger.net/web-security) | Free web app hacking labs with clear explanations |
| [Hack The Box Academy](https://academy.hackthebox.com/) | Structured modules, some free to start |
| [picoCTF](https://picoctf.org/) | Free beginner capture the flag challenges |
| [OverTheWire](https://overthewire.org/wargames/) | Learn Linux and security through wargames (start with Bandit) |
| [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) | Purposely vulnerable web app to practice on safely |
