# Investigation Resources

My go to list of free websites and tools for security investigations, threat research, and learning. I'll keep adding to it as I discover new ones.

> ⚠️ **Reminder:** Anything you paste into a public tool may be visible to others. Never submit private, sensitive, or confidential files, emails, or data.

## IP, Domain, and URL Reputation

| Tool | What it's good for |
|------|--------------------|
| [VirusTotal](https://www.virustotal.com/) | Check files, hashes, URLs, domains, and IPs against dozens of security vendors |
| [AbuseIPDB](https://www.abuseipdb.com/) | See if an IP has been reported for malicious activity |
| [urlscan.io](https://urlscan.io/) | Safely scan a website and see screenshots, redirects, and requests |
| [Cisco Talos Intelligence](https://talosintelligence.com/reputation_center) | IP and domain reputation lookups |
| [GreyNoise](https://viz.greynoise.io/) | Tell apart targeted attacks from internet wide scanning noise |
| [URLVoid](https://www.urlvoid.com/) | Website reputation across multiple blocklists |
| [IPinfo](https://ipinfo.io/) | IP geolocation, ASN, and hosting provider details |

## Threat Intelligence

| Tool | What it's good for |
|------|--------------------|
| [AlienVault OTX](https://otx.alienvault.com/) | Community threat intel and indicators of compromise (IOCs) |
| [MalwareBazaar](https://bazaar.abuse.ch/) | Look up malware samples by hash |
| [URLhaus](https://urlhaus.abuse.ch/) | Database of URLs used to spread malware |
| [ThreatFox](https://threatfox.abuse.ch/) | Shared IOCs linked to known malware families |
| [MITRE ATT&CK](https://attack.mitre.org/) | Framework of attacker tactics and techniques |

## Malware and File Analysis (Sandboxes)

| Tool | What it's good for |
|------|--------------------|
| [Hybrid Analysis](https://www.hybrid-analysis.com/) | Free malware sandbox with detailed behavior reports |
| [ANY.RUN](https://any.run/) | Interactive sandbox to watch malware run in real time |
| [Joe Sandbox](https://www.joesandbox.com/) | Deep automated malware analysis |

## Email and Phishing

| Tool | What it's good for |
|------|--------------------|
| [MXToolbox](https://mxtoolbox.com/) | Analyze email headers, check SPF, DKIM, DMARC, and blacklists |
| [Google Admin Toolbox Messageheader](https://toolbox.googleapps.com/apps/messageheader/) | Paste email headers to trace the delivery path |
| [PhishTank](https://phishtank.org/) | Community database of known phishing sites |

## Domains, DNS, and Recon

| Tool | What it's good for |
|------|--------------------|
| [ICANN Lookup](https://lookup.icann.org/) | Official WHOIS: who registered a domain and when |
| [DNSDumpster](https://dnsdumpster.com/) | Map a domain's DNS records and subdomains |
| [crt.sh](https://crt.sh/) | Search SSL certificate logs to discover subdomains |
| [Shodan](https://www.shodan.io/) | Search engine for internet connected devices and open ports |
| [Censys](https://search.censys.io/) | Internet wide scan data on hosts and certificates |
| [Wayback Machine](https://web.archive.org/) | See what a website looked like in the past |
| [Wappalyzer](https://www.wappalyzer.com/) | Identify technologies a website is built with |

## Windows and Logs

| Tool | What it's good for |
|------|--------------------|
| [Windows Security Log Encyclopedia](https://www.ultimatewindowssecurity.com/securitylog/encyclopedia/) | Explains what each Windows Event ID means |
| [LOLBAS](https://lolbas-project.github.io/) | Built in Windows tools that attackers abuse |
| [GTFOBins](https://gtfobins.github.io/) | Linux binaries that can be abused for privilege escalation |
| [Microsoft Learn: PowerShell](https://learn.microsoft.com/en-us/powershell/) | Official PowerShell documentation |

| Tool | What it's good for |
